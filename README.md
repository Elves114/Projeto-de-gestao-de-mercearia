# Projeto de gestao de mercearia
# Sistema de Gestão de Mercearia  API REST desenvolvida em **Java com Spring Boot** para a gestão de uma mercearia, com foco em organização, segurança, controle de estoque e operações de venda.  O projeto foi desenvolvido com uma arquitetura organizada e preparada para evolução, utilizando boas práticas de desenvolvimento e separação de responsabilidades.  ### Principais funcionalidades  * Gestão de empresas * Gestão de utilizadores e perfis de acesso * Autenticação e autorização com **Spring Security e JWT** * Gestão de produtos e categorias * Controle de estoque * Registro de movimentações de estoque * Gestão de vendas e itens vendidos * Auditoria das operações * Validações e regras de negócio * Isolamento dos dados por empresa  ### Tecnologias utilizadas  * Java * Spring Boot * Spring Security * JWT * Spring Data JPA / Hibernate * MySQL * Maven * Lombok * Docker * OpenAPI / Swagger  ### Objetivo  O objetivo do projeto é construir uma solução de gestão simples, segura e escalável para pequenos negócios, servindo também como um projeto prático para aplicar conceitos de **desenvolvimento de APIs REST, arquitetura de software, segurança, persistência de dados e regras de negócio**.  O backend foi desenvolvido e testado pensando na possibilidade de, futuramente, ser integrado a uma aplicação frontend independente.
